# Support

## Help and questions

Use [GitHub Discussions](https://github.com/mafk21/OS/discussions) for setup questions, usage help, ideas, and community conversation. Search existing discussions and documentation first.

## Bug reports

Use the repository's bug-report issue form and include your JARVIS version, operating system, Python version, reproduction steps, expected behavior, actual behavior, and sanitized logs.

Never post API keys, tokens, cookies, account data, personal files, recordings, screenshots containing private information, browser profiles, or complete runtime databases.

## Security reports

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) and use GitHub Private Vulnerability Reporting.

## Scope

Community support is best effort. The latest release is the supported version; old commits, modified forks, unsupported Python versions, and third-party plugins may not receive troubleshooting support.
